# LiveTalking 中文语音数字人 Demo 设计

## 目标

交付一个可重复启动的中文 Demo：用户既可以打字提问，也可以通过浏览器录音提问；系统显示识别文本与回答文本，并让 Wav2Lip 数字人用中文语音朗读回答、同步嘴型。启动入口保持为 Windows 桌面的 `启动数字人.bat`。

## 本次范围

- 全中文单页界面，仅保留连接状态、数字人视频、对话记录、文字提问、按键录音、发送和打断。
- 默认人物使用 `wav2lip_avatar_glass_man`。
- ASR 使用云端本地 SenseVoiceSmall/FunASR，录音结束后一次性识别，不做实时字幕流。
- LLM 使用云端本地 Qwen2.5-3B-Instruct，不依赖付费 API。
- TTS 使用 LiveTalking 已集成的 EdgeTTS 中文音色；必须通过启动时健康检查和端到端语音测试。
- WebRTC 使用云端 coturn，经 SSH 转发 `8010` 和 `3478`，强制 TURN/TCP 中继。
- 隐藏 Avatar 生成、管理后台、独立 TTS 管理、录制和动作编排等非核心入口。
- 医疗知识库、诊断建议和医疗 RAG 不在本次范围；后续作为独立阶段接入。

## 架构与数据流

### 文字提问

1. 浏览器建立 WebRTC 会话并取得 `sessionid`。
2. 用户输入中文问题并提交统一问答接口。
3. 后端调用本地 Qwen 生成简洁中文回答。
4. 回答文本写入该数字人会话；现有 EdgeTTS 合成语音，Wav2Lip 生成口型视频。
5. 浏览器展示问题、回答，并通过 WebRTC 播放音视频。

### 语音提问

1. 用户点击“开始说话”，浏览器通过 `MediaRecorder` 录制麦克风。
2. 用户点击“结束并发送”，浏览器上传单段 WebM/WAV 音频。
3. 后端将音频转换为 16 kHz 单声道 PCM，由 SenseVoiceSmall/FunASR 转写。
4. 转写文本复用文字提问流程，并将转写与回答一并返回页面。

## 后端组件

- 新增本地 ASR 服务封装：启动时加载一次模型，串行保护推理，返回标准化中文文本。
- 新增本地 LLM 服务封装：启动时加载 Qwen 模型，限制输出长度，避免占满显存。
- 新增统一问答接口：校验 `sessionid`、文本或音频，完成 ASR → LLM → Avatar/TTS 调用。
- 保留现有 `/offer`、`/human` 与会话管理机制，最小化对数字人推理链的改动。
- 启动脚本检查模型、人物、FFmpeg、coturn、ASR/LLM 权重，并输出明确错误。

## 前端组件

- 连接区：显示“正在连接 / 已连接 / 连接失败”，不再只显示笼统的 `Failed to fetch`。
- 对话区：展示用户问题、语音转写和数字人回答。
- 文字输入：回车或点击按钮发送。
- 语音输入：点击开始、点击结束并发送；录音时有明显状态。
- 权限错误、无声音、空识别、模型忙、网络中断均用中文提示。

## 资源和性能约束

- 所有模型和可持久化资源放在 `/root/autodl-tmp/LiveTalking` 或其子目录，避免实例重置后丢失。
- 4090 同时承载 Wav2Lip、3B LLM 和小型 ASR；LLM 使用半精度并限制并发为 1。
- 单用户 Demo 优先，最多保留一个活跃对话会话，避免失败会话耗尽上限。
- 浏览器录音长度默认限制为 60 秒，上传大小受限并拒绝非音频内容。

## 错误处理

- WebRTC 或 TURN 不可用：阻止发送并给出中文修复提示。
- ASR 识别为空：不调用 LLM，提示重新录音。
- LLM 失败：返回中文错误且不触发 TTS。
- EdgeTTS 网络失败：页面显示语音合成失败，保留文本回答便于定位。
- 任一模型缺失：启动脚本失败退出并指出缺失路径，不以“启动成功”误导用户。

## 验收与测试

- 静态检查：主页核心可见文案为中文，不出现无用入口。
- 启动测试：双击桌面脚本后，HTTP `8010`、TURN/TCP `3478` 均可达。
- WebRTC 测试：状态变为“已连接”，视频元素获得有效流且画面尺寸大于 0。
- ASR 测试：一段中文测试音频能得到非空、合理的中文转写。
- LLM 测试：中文问题能在限定时间内得到非空中文回答。
- TTS/Wav2Lip 测试：回答产生音频，数字人视频帧持续更新并出现嘴型变化。
- 重启测试：停止并重新运行一键脚本后，上述主流程仍可完成。

## 安全边界

- TURN 端口只通过 SSH 转发到本机，不直接暴露公网。
- Demo 不保存麦克风录音和对话内容；临时文件处理完成后删除。
- 当前模型仅用于通用演示，不输出“已验证医疗诊断”或替代医生的声明。
