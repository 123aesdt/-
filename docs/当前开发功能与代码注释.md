```text

                                    ├─> 本地 Qwen 生成回答
按住说话 ─录音转 WAV─POST /humanaudio─┘          │
                                                  v
                                           TTS 合成语音
                                                  │
                                                  v
                                     Wav2Lip 生成口型视频帧
                                                  │
                                                  v
                               WebRTC + TURN ──> 浏览器播放
```

## 3. 本地 Qwen 问答

### 相关文件

- `config.py`：允许 `local_qwen` 作为大模型提供方。
- `config.yaml`：当前默认使用本地 Qwen，模型目录为 `/root/autodl-tmp/dir`。
- `llm.py`：负责加载、缓存和调用本地模型，再把答案交给数字人播报。
- `tests/test_local_qwen.py`：验证“模型回答”确实被送入 Avatar，而不是把用户原话复读。

### 核心代码（带说明）

```python
_LOCAL_QWEN_CACHE = {}             # 模型缓存：避免每问一句都重新加载几十 GB 模型
_LOCAL_QWEN_LOCK = threading.Lock() # 并发锁：避免两个请求同时重复加载模型

def _load_local_qwen(model_path: str):
    device = 'cuda' if torch.cuda.is_available() else 'cpu'  # 优先使用 4090
    dtype = torch.float16 if device == 'cuda' else torch.float32
    tokenizer = AutoTokenizer.from_pretrained(
        model_path,
        local_files_only=True,      # 只读算力云本地模型，不临时联网下载
    )
    model = AutoModelForCausalLM.from_pretrained(
        model_path,
        local_files_only=True,
        dtype=dtype,
    ).to(device).eval()
    return tokenizer, model, device
```

```python
def _generate_local_qwen(message: str, opt) -> str:
    # 给模型设置中文医疗助手身份；这里只提供一般健康信息，不做确诊。
    messages = [
        {'role': 'system', 'content': '你是一名中文医疗健康咨询助手……'},
        {'role': 'user', 'content': message},
    ]
    # 使用 Qwen 自带对话模板，生成最多 256 个新 token。
    output = model.generate(**inputs, max_new_tokens=256, do_sample=False)
    return tokenizer.decode(output[0][prompt_length:], skip_special_tokens=True).strip()
```

```python
def llm_response(message, avatar_session, datainfo={}):
    if _llm_provider(opt) == 'local_qwen':
        answer = _generate_local_qwen(message, opt) # 真正生成答案
        avatar_session.put_msg_txt(answer, datainfo) # 答案交给 TTS/Wav2Lip 播报
        return
```

### 核心代码（带说明）

```javascript
function audioBufferToWavBlob(audioBuffer) {
  // 多声道求平均，合并为后端更容易识别的单声道音频。
  const mono = new Float32Array(audioBuffer.length);

  // 写入 RIFF/WAVE 文件头：PCM、单声道、16 bit。
  writeAscii(view, 0, 'RIFF');
  writeAscii(view, 8, 'WAVE');
  view.setUint16(22, 1, true);  // 1 个声道

  // 浮点采样值限制到 [-1, 1]，再转为 Int16 PCM。
  view.setInt16(offset, sample < 0 ? sample * 32768 : sample * 32767, true);
```

## 7. 一键启动

### 云端 `start.sh`

启动顺序如下：

1. 定位项目目录。
2. 检查 `models/wav2lip.pth`。
3. 检查并校验指定 Avatar。
4. 检查并启动 coturn（3478，媒体中继端口 49160–49200）。
5. 避免重复启动相同 Avatar。
6. 后台启动 `app.py`，日志写入 `livetalking.log`。

```bash
AVATAR_ID="${AVATAR_ID:-renhe_hospital_doctor}" # 可通过环境变量切换数字人
python tools/validate_avatar_asset.py "$AVATAR_DIR" --min-frames 50

nohup python app.py \
  --transport webrtc \
  --model wav2lip \
  --avatar_id "$AVATAR_ID" \
  --stun "turn:127.0.0.1:3478?transport=tcp" \
  --listenport 8010 \
  >livetalking.log 2>&1 </dev/null &
```

### Windows `启动数字人.bat`

它负责：

1. SSH 登录算力云并执行 `start.sh`。
2. 新开一个不能关闭的 SSH 隧道窗口。
3. 把本机 `8010` 和 `3478` 分别转发到算力云。
4. 自动打开 `http://127.0.0.1:8010/index.html`。

核心命令：

```bat
ssh autodl-livetalking "cd /root/autodl-tmp/LiveTalking && ./start.sh"
start "LiveTalking SSH 隧道（请勿关闭）" powershell.exe -NoExit -Command ^
  "ssh -N -L 8010:127.0.0.1:8010 -L 3478:127.0.0.1:3478 autodl-livetalking"
start "" "http://127.0.0.1:8010/index.html"
```

## 8. Avatar 资源校验

### 相关文件

- `tools/validate_avatar_asset.py`：正式校验程序。
- `tests/test_validate_avatar_asset.py`：覆盖数量不一致、正常资源、尺寸不一致和启动脚本调用四种情况。

### 校验内容（带说明）

```python
full_files = sorted((avatar_path / 'full_imgs').glob('*.png')) # 完整人物帧
face_files = sorted((avatar_path / 'face_imgs').glob('*.png')) # 人脸裁剪帧
coords = pickle.load(open(avatar_path / 'coords.pkl', 'rb'))    # 每帧人脸坐标

# 三者必须一一对应，否则运行中会错帧、黑屏或直接报错。
if len({len(full_files), len(face_files), len(coords)}) != 1:
    return ValidationResult(False, '资源数量不一致')

# 同一组序列中图片尺寸必须固定，避免视频合成失败。
full_size = _image_size(full_files, '完整帧')
face_size = _image_size(face_files, '人脸帧')
```
